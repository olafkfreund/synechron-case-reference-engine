# Spec: the portal uses the Synechron business web template's brand

## Design

### 1. Colours: new values in the existing token block

Only the values change, in `app/static/portal.css` between `/* tokens */` and `/* end tokens */`. The token names, the three blocks and the rules that use them stay as they are:
- light `:root`
- the OS-dark media query
- `[data-theme="dark"]`

The two dark blocks hold the same values, as `test_theme_contrast` requires.

The brand's OKLCH values are converted to hex. Where a brand colour fails a contrast pair, a darker or lighter step of the same hue is used, as noted.

### 2. Type, corners and the shadow

- **Body text:** `--fs-m` goes from 15px to 16px. The two literal `15px` sizes in `portal.css` become `var(--fs-m)` or keep their purpose; the plan lists each one.
- **Corners:**
  - `--r-control` goes from 10px to 8px, the brand's 0.5rem.
  - `--r-card` goes from 14px to 8px.
- **Fonts:** no change. Montserrat, already self-hosted under the OFL, is the brand typeface, and IBM Plex Mono stays for the tag and code.

### 3. Logo in the header

- **New partial, `app/templates/_logo.html`:**
  - **The logo:** the template's `public/logo.svg` paths (viewBox `0 0 678 138`), cleaned:
    - no `<style>` block, no Illustrator comments and no fixed colour
    - every path uses `fill="currentColor"`
    - `role="img"` with `aria-label="Synechron"`
  - **The brandmark:** the template's `brandmark.svg`, cleaned the same way.
- **`base.html`:** the `.brand` link shows the logo, then the product name "Reference Engine". The product name stays as text.
- **Colour:** the logo takes `color: var(--header-strong)`. That gives navy `#001422` in light mode and `#F4F4F4` in dark mode, the brand's "navy or white only" rule.
- **Size:**
  - The logo is 200 px wide (height about 41 px).
  - In the existing narrow-screen media query, where `.brand-tag` is already hidden, the logo is hidden and the brandmark is shown at 32 px instead.
- **Hover:** `.site-header .brand:hover{color:var(--header-strong)}` is unchanged, and `test_brand_hover_uses_the_header_colour_and_theme_js_follows_the_os` checks it.

### 4. What does not change

- **Page markup:** no page template changes. The changes are the header, the new partial and CSS.
- **JavaScript:** `theme.js`, `review.js` and the toggle markup stay as they are.
- **The template's code:** none of its React, Tailwind, shadcn or Next.js comes in.
- **Template documents:** the brand PDF and guideline documents are not copied.
- **Cache-busting:** the `css_version` hash covers `portal.css`, so browsers fetch the new theme. The logo is inline, so there is no new static file to cache-bust.

## Alternatives rejected

- **Adopting the template's Next.js and Tailwind app.** It would rewrite every page and add a JS build, a runtime and dependencies, for a look that CSS variables already give us.
- **Loading Montserrat from Google Fonts, as the template does.** It's already self-hosted, and an external font request would need security header changes and send a request to a third party.
- **The logo as `<img src="logo.svg">`.** An image can't follow the theme colour, so it would need two files and a CSS swap. Inline `currentColor` is one file and always matches.
- **The brand Light Blue `#26A9E0` exactly for links and focus in light mode.** It fails 4.5:1 as text and 3:1 as a focus ring on the light page. A darker step of the same hue passes.
- **Making the dark-mode accent near-white,** as the template's dark primary is. White active tabs on navy lose the brand blue. Light Blue with navy text passes and stays on brand.

## Risks

- **Bigger dense screens.** 16 px text makes the review rows and wide tables about 7% bigger, so some tables scroll sideways sooner. The intent accepted this.
- **A crowded header on mid-width screens.** The 200 px logo makes it busier. The nav already wraps, and the brandmark takes over below the existing breakpoint. Checked by a screenshot at 1280, 900 and 390 px.
- **Rules that reference the old colours.** A rule that relied on amber, such as the avatar or a badge using `--accent`, changes colour with the token. The plan lists each use of `--accent`, `--on-accent` and `--link` to check.
- **Logo rights.** The template marks the logo "Synechron confidential, internal use". The requester confirmed it may ship in this internal repo (intent question 1).
