  - change `--fs-m`, `--r-control` and `--r-card`

  - `:94-95`, the primary buttons

  - The media and toggle dark blocks must be identical.

### 2. Logo partial and header (Codex)

- **New `app/templates/_logo.html`:**
  - **`{% macro logo() %}`:** the paths from the template's `public/logo.svg` (viewBox `0 0 678 138`).
    - Drop the `<?xml`, comments, `<style>`, `class`, `id`, `style`, `xml:space` and `enable-background`.
    - Keep any `clipPath` only if the paths need it; give it a fixed id `syn-logo-clip`.
    - Every visible shape uses `fill="currentColor"`.
    - Attributes: `class="brand-logo" role="img" aria-label="Synechron" focusable="false"`.
  - **`{% macro brandmark() %}`:** the same treatment for `public/brandmark.svg` (viewBox `0 0 5669.3 5669.3`), with `class="brand-mark"`.
- **`app/templates/base.html:3` and `:9`:**
  - import the partial with `{% from "_logo.html" import logo, brandmark %}`
  - the brand link becomes `<a class="brand" href="/">{{ logo() }}{{ brandmark() }}<span class="brand-name">Reference Engine</span><span class="brand-tag">bids &amp; presales</span></a>`
- **`portal.css`, outside the tokens block:**
  - `.brand{align-items:center}`, instead of `baseline`, so the logo lines up with the text
  - `.brand-logo{width:200px;height:auto;color:var(--header-strong);flex:none}`
  - `.brand-mark{display:none;width:32px;height:32px;color:var(--header-strong);flex:none}`
  - inside the existing `@media (max-width:699px)` block (`:366`): `.brand-logo{display:none}.brand-mark{display:block}`
  - keep `.site-header .brand:hover{color:var(--header-strong)}` exactly as it is
- **Traps:**
  - No `<style`, `style="…color…"` or `color="` in templates (`test_templates_have_no_inline_colours`).
  - No colour literals outside the tokens block.
  - Edit only `_logo.html`, `base.html` and `portal.css`, outside the tokens block.
