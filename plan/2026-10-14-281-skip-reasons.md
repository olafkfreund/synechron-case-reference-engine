# Plan: research says why sources were skipped

## Approved decisions (from the spec)

- **Reasons come from the stored class name.** Each skipped entry is
  `{"domain", "error": <class name>}` (`app/research.py:840`). It is mapped
  when the page is drawn. **Nothing new is stored**, so older rows work too.
- **Mapping:**

  | Stored `error` | Shown reason |
  |---|---|
  | `RobotsDisallowed` | don't allow automated access |
  | `Stalled`, `ConvertTimeout`, any name ending in `Timeout` | didn't respond in time |
  | any other httpx exception class name | couldn't be reached |
  | `TooLarge` | too large |
  | `BadContentType`, `ConvertFailed` | not a web page or PDF |
  | `ResearchError` | refused by the server |
  | `Blocked` | blocked by our safety checks |
  | anything else | other errors |

- **Hidden-source placeholders `{}`** (`research.py:250`) count toward the
  total but get no reason.
- **No domain reaches the template.**
- **`research.py:465` raises `Stalled`** instead of a plain `ResearchError`.
- **Line format:**
  - "8 source(s) skipped: 6 don't allow automated access, 2 didn't respond in time."
  - reasons are ordered largest first
  - when no entry has a reason, the line stays "8 source(s) skipped."

## Steps

1. **`app/research.py`**
   - **Errors (after `ConvertFailed`, ~`:75`):** add `SKIP_REASONS`, a
     dict from class name to label, following the table above, and
     `skip_reason(name) -> str | None`:
     - `None` for a missing name
     - a dict hit returns its label
     - a name ending in `Timeout` → "didn't respond in time"
     - a name that is an exception class in `httpx` (check with
       `getattr(httpx, name, None)`) → "couldn't be reached"
     - otherwise "other errors"
   - **`:465`:** `raise ResearchError("fetch took too long")` becomes
     `raise Stalled("fetch took too long")`.
   - **`research_view`, after `:250`:** build
     `skip_reasons = Counter(r for s in skipped if (r := skip_reason(s.get("error")))).most_common()`
     and pass it to the template. `Counter` is from `collections`; check the
     imports.

   Verify by: `python -c` import of the module in the app image.
   Traps: build the image before any test run (stale-image memory).
